=== How to read this ===

- Both arms come from GitHub search with the same structural filters (>=5 .py
  files, 50-50000 KB, app not library/course, 2024-2026, 1-50 stars). The AI
  arm is defined by self-declaration (vibe queries plus README/bot evidence);
  the traditional arm by the absence of any AI mention and of bot commits.
- The traditional arm comes from generic Python queries, not from a census of
  all Python repos, so the base rate is a sample estimate, not a population
  parameter. Different queries, same coarse profile.
- Licences are as GitHub reports them. NOASSERTION means a licence file that
  GitHub cannot map to an SPDX id, counted separately rather than as unlicensed.
